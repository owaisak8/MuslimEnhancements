# Muslim Enhancements - Islamic Faiths (1.20 'Crozier' structure)
#
# Faith			Rites (main first)
# sadr_al_islam	nabi, sahabah, tabiun	(vanilla faith; replaces ME's old Non-Sectarian Islam religion)
# sunni			hanafi, maliki, shafii, hanbali, mutazila, karrami
# masmudi		masmudi
# shia			ismaili, hafizi (1132+), tayyibi (1132+), nizari	(vanilla key kept, named Isma'ilism in ME)
# ithna_ashari	imami (Ja'fari)	(named Ja'farism)
# alevi			alevi
# zayidi		zayidi, salihi
# qarmatian		qarmatian, baqli
# druze			druze
# ibadi			ibadi, wahbiya, nukkari	(d_ibadi is the Head of Faith; the Rustamid Imamate d_wahbiya is a head of Rite)
# kharijite		azariqa
# najdat		najdat
# sufri			sufri
# quranist		quranist	(disabled: cannot be converted to)
# ghulat			alawite (Nusayri), ghulat (Ikhtilafism; disabled: cannot be converted to)
# (Berberist faiths are in me_faith_types_berberist.txt)
